# CineLog

CineLog adalah aplikasi web berbasis Laravel dan Tailwind CSS yang berfungsi sebagai galeri/katalog personal untuk menampilkan koleksi film bioskop favorit. Aplikasi ini dilengkapi fitur login, dashboard, daftar tontonan (My Watchlist), serta halaman profil yang memiliki modal pop-up edit profil dan konfirmasi logout.
